# SSCP 测试与复现指南

[Testing Guide (English)](../../test/README.md) · [使用手册](使用手册.md) · [项目 README](../../README.md)

本指南说明如何运行 SSCP 的自动化测试套件、复现各种网络损耗实验，以及使用 jPlot 工具进行可视化分析。

## 测试环境分类

| 环境类型 | 验证目的 | 工具与后端 |
|---|---|---|
| **确定性虚拟网络** | 验证协议正确性、丢包重传、状态转移与定时器清理，无需等待物理时间 | `sscp_virtual` + `vnet.c` (1 μs 仿真时钟) |
| **真实 UDP 本地回环** | 验证套接字 I/O、实际操作系统调度与大文件传输正确性 | `sscp_udp` + `run.py` (真实物理时钟) |
| **Linux 网络命名空间** | 在真实 Linux 内核网络与 qdisc netem 损伤（丢包、限速、延迟）下测试 | `setup_sscp_netns.sh` + `ip netns` |

## 构建与运行测试

### 1. 编译所有测试目标

```sh
cmake -S test -B test/build -DCMAKE_BUILD_TYPE=Release
cmake --build test/build -j
```

### 2. 执行虚拟网络测试集 (CTest)

运行由 CTest 调度的 11 项端到端虚拟网络测试：

```sh
ctest --test-dir test/build -L virtual --output-on-failure
```

测试覆盖：
- 握手 ACK 丢失与超时恢复
- 连接生命周期与立即关闭
- 乱序接收序列号回绕检查
- Pacing 起步调度时序
- 高丢包率下的可靠传输与 FNV-1a 数据校验
- 拥塞控制器（AIMD 与 PROB）在固定延迟下的传输行为

### 3. 执行真实 UDP 双端传输

使用 `test/run.py` 调度双端进程进行数据传输与校验：

```sh
# 传输 8 MiB 数据
python3 test/run.py test/build/sscp_udp --bytes 8388608 --out test/results/udp-test
```

### 4. Linux Netem 损伤实验

使用根目录的脚本创建双端命名空间拓扑（客户端 `sscp-c`、路由器 `sscp-r`、服务端 `sscp-s`）：

```sh
# 配置：5 Mbps 带宽，50 ms 单向延迟 (100 ms RTT)，10% 丢包，1000 包队列上限
sudo bash setup_sscp_netns.sh setup 5mbit 50ms 10% 1000

# 终端 1 运行服务端 B
sudo ip netns exec sscp-s test/build/sscp_udp B 10.0.2.1 104857600 aimd

# 终端 2 运行客户端 A
sudo ip netns exec sscp-c test/build/sscp_udp A 10.0.2.1 104857600 aimd

# 实验结束清理拓扑
sudo bash setup_sscp_netns.sh teardown
```

## 轨迹可视化 (jPlot)

传输测试会记录逐包状态日志。使用离线转换器将日志转为 `.xpl` / `.tsg` 格式，并通过交互式工具查看：

```sh
python3 test/sscptrace.py test/results/udp-test -o test/results/udp-test/trace.xpl
java -jar jPlot.jar test/results/udp-test/trace.xpl
```

jPlot 界面支持：
- 滚轮无级缩放时间轴
- 查看首发包与重传包时序
- 观察拥塞窗口（cwnd）与平滑 RTT（SRTT）曲线变化
