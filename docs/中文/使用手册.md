# scp 使用手册

scp 是 一个可靠流传输层，提供序号、确认、重传、窗口、乱序重组、拥塞控制等功能。
 它不关心底层链路，也不关心上层协议，只负责可靠传输。

## 时钟

我们需要实现一个时钟获取函数，在任意可链接到的文件中实现即可，建议使用一个uint32_t的全局变量，每1ms递增即可，获取时钟时返回该变量的值即可。

```c
extern uint32_t scp_now_time(void);
```

## Pacing 策略

拥塞窗口和接收窗口允许的数据按 `gap = payload_bytes * RTT / (gain * cwnd)` 分配预约时刻。每批从 `max(next_slot, now)` 开始，先给包分配当前槽，再按该包间隔推进 next-slot。发送队列为空时也保留尾槽，让下一批继续遵守前一个包的 pacing 间隔。

AIMD 使用固定阶段系数：SS 为 `2 ln 2` 对应的 Q16 值 `90852`，CA 为 `3 ln 3 / 2` 对应的 Q16 值 `107998`。PROB 全程使用 CA 系数；CA 的实际值为 `107998 / 65536 = 1.647918701171875`。每种控制器通过各自注册的回调提供 gain。尚无 RTT 样本时使用 1 ms 回退值，应用仍需周期性处理定时器。

[论文](../../Pacing_and_Congestion_Window_Growth.pdf)依次解释连续模型、离散包时序和三明治推导。[测试说明](../../test/README.md#model-and-execution-contract)区分 Python 模型、实际 SCP 核心的虚拟网络实验和真实 UDP 测量。

## API

### 初始化

```c
int scp_init(size_t max_streams);
```

初始化 SCP，全局只有一份。

### 分配流

```c
struct scp_stream *scp_stream_alloc(struct scp_transport_class *st_class,
                                    int src_fd,
                                    int dst_fd);
```

创建一个流，绑定底层传输类。

**注意**

fd就是结构体的映射，由用户自由分配，同一时刻，一个节点上，fd不能重复。

### 释放流

```c
int scp_stream_free(struct scp_stream *ss);
```

释放流。

### 连接

```c
int scp_connect(int fd);
```

这个函数会与远程scp协议进行握手。

### 输入数据

```c
int scp_input(void *ctx, void *buf, size_t len);
```

输入一整个 SCP 包，SCP 会自动处理序号、确认、重传等逻辑。

### 发送数据

```c
int scp_send(int fd, void *buf, size_t len);
```

向指定 fd 的流发送数据。

### 接收数据

```c
int scp_recv(int fd, void *buf, size_t len);
```

从指定 fd 的流读取数据。

### 关闭流

```c
void scp_close(int fd);
```

挥手，关闭流。

### 定时器处理

```c
void scp_timer_process();
```

SCP 的 pacing、重传、保活、persist 等定时器事件都依赖此函数。应在调用 SCP 的线程中周期性处理，即使没有收到数据包也要调用；只在收包后调用可能使已预约发送停滞。建议以 1 ms 节拍处理，与 pacing 定时器粒度一致。

### 宏配置

头文件中的宏可根据需求进行配置。



## 多线程注意

SCP默认单线程，如果要多线程使用，建议用户在外层给这些API加上一个全局锁。
