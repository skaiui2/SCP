# SSCP 使用手册

[User Guide (English)](../English/UserGuide.md) · [项目 README](../../README.md) · [测试说明](测试说明.md)

SSCP 是一个构建在 UDP 之上的轻量级可靠流传输层，提供严格保序、确认重传、滑动窗口、乱序重组与拥塞控制功能。

## 时钟要求

接入方需提供单调递增的 `uint32_t` tick 时钟。`SSCP_TICK_SCALE` 定义每毫秒包含的 tick 数：
- 真实 UDP / 实际部署环境默认 `1U`（即 1 tick = 1 ms）。
- 确定性虚拟网络仿真环境默认 `1000U`（即 1 tick = 1 μs）。

```c
extern uint32_t sscp_now_time(void);
```

物理超时常数按时钟刻度换算：
- 初始重传超时（RTO）为 1000 ms。
- 获得 RTT 样本后，动态 RTO 钳位在 200 ms 到 2000 ms 之间。
- 未建立 RTT 样本前，Pacing 调度默认按 1 ms 发送间隔回退。

## Pacing 发送调度策略

在拥塞窗口与对端接收窗口允许的情况下，数据包按如下公式计算调度时间间隔：
`gap = payload_bytes * RTT / (gain * cwnd)`

- 发送批次从 `max(next_slot, now)` 开始。
- 每个数据包持续推进持久的 `next_slot`，即使发送队列抽空也保留尾槽，确保下一批发送遵守前序间隔。
- AIMD 在慢启动（SS）阶段使用 `2 ln 2`（Q16 为 `90852`），在拥塞避免（CA）阶段使用 `3 ln 3 / 2`（Q16 为 `107998`）。
- PROB 控制器全程采用 CA 增益系数。

## API 接口说明

### 1. 协议引擎初始化

```c
int sscp_init(size_t max_streams);
```
初始化 SSCP 全局子系统与内部对象池。创建流之前必须调用且仅调用一次。

### 2. 流创建与底层传输绑定

```c
struct sscp_stream *sscp_stream_alloc(struct sscp_transport_class *st_class,
                                      int src_fd,
                                      int dst_fd);
```
分配一个 SSCP 流实例，并绑定底层包发送与接收回调结构体 `st_class`。
`src_fd` 为本地协议流标识，`dst_fd` 为对端标识（非操作系统 socket 套接字）。

### 3. 选择拥塞控制算法

```c
int sscp_set_cc(int fd, enum sscp_cc_id cc_id);
int sscp_prob_configure(struct sscp_stream *ss, uint32_t rtt_span_ms, uint32_t loss_q16);
```
在流处于 `SSCP_CLOSED` 状态时，选择使用 `SSCP_CC_AIMD` 还是 `SSCP_CC_PROB`。

### 4. 发起连接握手

```c
int sscp_connect(int fd);
```
向对端发起 CONNECT 三次握手建立连接。

### 5. 输入包驱动

```c
int sscp_input(void *ctx, void *buf, size_t len);
```
将底层收到的 UDP 数据包送入 SSCP 协议引擎，由其完成解析、ACK 确认生成、状态转移和乱序处理。

### 6. 发送数据

```c
int sscp_send(int fd, void *buf, size_t len);
```
将用户数据写入发送缓冲区。
- 返回 `0` 表示成功加入队列；
- 返回 `SSCP_ERR_NOBUF` (-2) 表示发送缓存满，调用方应等待后重试；
- 返回 `SSCP_ERR_GENERIC` (-1) 表示流无效或状态不合法。

### 7. 接收数据

```c
int sscp_recv(int fd, void *buf, size_t len);
```
从接收队列读取已排序就绪的载荷数据。返回实际复制的字节数；返回 `0` 表示当前暂无数据。

### 8. 连接关闭

```c
void sscp_close(int fd);
int sscp_is_closed(int fd);
```
`sscp_close` 触发优雅断开连接（等待队列中剩余数据送达并发送 FIN）。
`sscp_is_closed` 检查当前流是否已完全关闭。

### 9. 定时器驱动

```c
void sscp_timer_process(void);
```
轮询并推进所有活动定时器（Pacing 发包、超时重传、保活探测等）。事件循环中应周期性调用。

## 线程模型

SSCP 针对单线程事件循环设计。若在多线程环境下访问同一流实例，调用方必须使用外部锁对所有 SSCP API（包括 `sscp_timer_process`）进行串行化保护。
